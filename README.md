# 3D Surfaces Dashboard — 01417112 Calculus II & 02731112 Calculus of Several Variables

Interactive 3D teaching dashboard for **Chapter 1: Surfaces in 3D Space** (Faculty of Science at Sriracha, Kasetsart University), supporting bilingual (`TH | EN`) and course switching (`01417112 Calculus II` and `02731112 Calculus of Several Variables`).

## Features (Chapter 1)
1. **3D Coordinates & Octants (`?tab=coords`)**: Step-by-step plotting $P(x,y,z)$, orthogonal distance projections, Octants I–VIII, and coordinate planes ($xy, xz, yz$).
2. **Planes (`?tab=planes`)**: Axis intercepts, parallel planes & traces on coordinate planes, plus reference plane comparisons ($x=0, y=0, z=0$).
3. **Quadric Surfaces (`?tab=quadrics`)**: Course-tailored surface explorer (4 core surfaces in `01417112`, + Elliptic Cone & Hyperbolic Paraboloid in `02731112`), live axis intercepts, 2D slice trace cross-sections, and Quiz Mode.
4. **Cylinders (`?tab=cylinders`)**: Elliptic, Parabolic, and Hyperbolic Cylinders with missing-variable rulings, 2D trace inspection, and Quiz Mode.
5. **Translation of Axes (`?tab=translation`)**: Completing-the-square walkthrough, ghost surface at $(0,0,0)$, shifted axes $x', y', z'$, and Quiz Mode across Ellipsoid, Elliptic Paraboloid, Hyperboloids (1- & 2-Sheet), Cone, and Elliptic Cylinder.
